# Ficha inicial: as IAs que você usa hoje

Preencha antes da aula 01 e guarde. No projeto final, você volta nela e compara o que achava com o que encontrou.

Liste cada ferramenta de IA que você usa no trabalho: chat, agente de código, automação, bot de atendimento, extensão do navegador, app feito com IA. Uma linha por ferramenta.

| Ferramenta | Para que eu uso | O que ela acessa (arquivos, e-mail, agenda, banco, terminal, cartão) | Com que conta ela entra (minha, da empresa, uma só dela) | O que eu acho que está protegido, e por quê |
|---|---|---|---|---|
| | | | | |
| | | | | |
| | | | | |
| | | | | |

Exemplo de uma linha preenchida:

| Ferramenta | Para que eu uso | O que ela acessa | Com que conta ela entra | O que eu acho que está protegido |
|---|---|---|---|---|
| Agente de código no terminal | Corrigir o site da loja | A pasta do projeto, o terminal e o `.env` com a chave do gateway | A minha conta do GitHub | Acho que ele só mexe na pasta do projeto, porque eu aprovo os comandos |

Três perguntas para fechar a ficha:

1. Qual dessas ferramentas faria mais estrago se alguém de fora mandasse nela?
2. Alguma delas entra com a sua conta pessoal, a mesma do seu e-mail e do banco?
3. Você sabe onde está cada chave de API que essas ferramentas usam?
